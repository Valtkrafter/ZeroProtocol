# AI Handoff Log

Newest entry first. Keep the newest 5 entries here; move older ones to `Docs/handoff_archive/YYYY-MM.md`. Read [AI_Context.md](AI_Context.md) first.

## Protocol (every AI: Claude Code, Antigravity)
1. **Start:** read `Docs/AI_Context.md` and the newest entry below, then run `git log --oneline -10` and `git status --short`. If something changed after the entry's date, tell the user before you continue.
2. **Work:** do not touch what "Don't touch" lists. If a background job is running (sub-agent, render, build), do not start a second one on the same files.
3. **Stop or switch:** add a new entry at the top (template below), update `AI_Context.md` if a durable decision changed, commit everything as `handoff: <from> → <to>`, do not push. Claude Code: `/handoff`. Antigravity: the user says "handoff"; include your own plan or walkthrough summary under "Plan / what I did".
4. **Keep entries short:** about 20 lines at most. Git has the details; the entry is for why and what's next.

## Entry template

```
## YYYY-MM-DD HH:MM — <Tool> (<model>) → <next tool or "open">
**Asked:** what the user wanted, in one line.
**Plan / what I did:** the plan followed and the outcome, 3-6 bullets.
**Changed:** files or areas, commit range `abc1234..def5678`, files left uncommitted.
**Decisions:** what the user decided (also add it to AI_Context.md).
**Open / next:** unfinished work, questions waiting for the user, known bugs, running background jobs.
**Don't touch:** files or areas in progress or protected.
```
